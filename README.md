# Personal Finance Manager

**Personal Finance Manager** is an academic Django-based web application that helps users **systematically manage personal financial records** such as income, expenses, and budgets.  
The application focuses on **secure data handling, structured financial analysis, and introductory machine learning concepts**, making it suitable for learning and demonstration purposes.

---

## 📌 Project Overview

The system allows users to digitally record financial transactions and view summarized insights through a user-friendly interface.  
It also introduces **basic predictive analytics and classification techniques** to analyze spending behavior, aligning with academic coursework in web development and AI/ML fundamentals.

---

## ✨ Key Features

- Secure user authentication and session management  
- Income and expense recording with category support  
- Budget creation and expense monitoring  
- Financial summaries and trend analysis  
- Introductory ML-based forecasting and classification  
- Password recovery and account management workflows  
- Role-safe and session-protected user access  

---

## 🧰 Technology Stack

- **Backend:** Django (Python)
- **Frontend:** Django Templates, HTML5, CSS3, JavaScript
- **Database:** SQLite (via Django ORM)
- **ML Concepts:** Basic forecasting and classification models (educational level)

---

## 🗂️ Project Structure

- **personal-financial-manager/**
  - **accounts/** – Handles user authentication, registration, and profile management  
  - **finance/** – Manages income and expense recording, tracking, and categorization  
  - **budget/** – Responsible for budget planning, limits, and monitoring  
  - **templates/** – Contains HTML templates for rendering the user interface  
  - **static/** – Stores static assets such as CSS and JavaScript files  
  - **manage.py** – Django project management and command-line utility  
  - **requirements.txt** – List of Python dependencies required for the project
